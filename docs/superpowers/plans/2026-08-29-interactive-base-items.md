# Interactive Base Items Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Placed decorations can be turned on and off by tapping them in the room, animating with pure CSS and persisting across sessions; ship it with three items — TV, Stereo, Lava Lamp.

**Architecture:** Declarative. A catalog entry gains `interactive: true` + `effect: "<name>"`; a placed item gains an optional `on` flag. `App.room` gets `isInteractive(id)` and `toggleItem(world, id)`. `renderRoom` keeps a small `FX` map of `effect → overlay HTML`, renders the overlay inside the `.deco` span when `on`, and wires a tap → `opts.onToggle(id)` handler on interactive items in the normal room view. `gamescreen` supplies `handleToggleItem`, which flips the flag, persists, and re-renders. No new module, no `state.js`/`interactions.js` changes, no save-version bump.

**Tech Stack:** Zero-build vanilla HTML/CSS/JS (no framework, no bundler, no npm packages) under `potato-pet/`. Headless test runner `potato-pet/run-suite.mjs` on Node 23. Deterministic pixel-art generator `tools/gen-art.mjs` (Node, `node:zlib`, no deps).

**Spec:** `docs/superpowers/specs/2026-08-29-interactive-base-items-design.md`

## Global Constraints

- Every `potato-pet/js/*.js` file starts `window.App = window.App || {};` then attaches its API via an IIFE. Match this pattern; no ES modules, no `import`/`export`, no new dependencies.
- Headless tests run with `node potato-pet/run-suite.mjs` (runs every `*.tests.js`; there is no single-file runner). A green run prints `<N> / <N> passed`; a failure prints lines starting `FAIL`.
- Do **not** bump `App.save.CURRENT_VERSION` (stays `1`). A missing `on` on a placed item reads as off, exactly like the existing `pet.pos` / `pet.petLog` fields.
- No `potato-pet/js/state.js` or `potato-pet/js/interactions.js` changes — interactive items are purely cosmetic.
- Browser verification requires `potato-pet/js/config.js` to have `apiBase: ""`. Blank it with `sed -i 's#apiBase: "https://[^"]*"#apiBase: ""#' potato-pet/js/config.js`, and **always** restore it with `git checkout potato-pet/js/config.js` before committing.
